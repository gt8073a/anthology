Include Name: Numbers and Operations
Include ID: content_numbers_operations
Include Desc: Focused lesson on numbers, counting, and basic calculations. Injectable into any active book.

## Learning Goals
- Count from 0–10 in the target language
- Count from 11–20 and perform simple addition and subtraction
- Count in tens and hundreds; apply numbers in practical scenarios (measuring, buying, time)

## Hands

### Hand 1: Introduction to Numbers
Learning Goal: Count from 0–10 in the target language.
Vocabulary: Numbers 0–10
Verbs: count

Rules:
- Generate scenarios where the player counts objects in context (use the active book's setting).
  e.g. farsi-workplace: count the chairs in the meeting room
  e.g. pinegrove-general: count the medications on the tray
- Age group adaptations:
  Family: 0–5 objects
  Tweens: 0–8 objects
  Young Adult / Adult: 0–10 objects
- Reinforce through NPC dialogue where natural.

### Hand 2: Numbers 11–20 and Basic Operations
Learning Goal: Count from 11–20, perform simple addition and subtraction.
Vocabulary: Numbers 11–20, plus, minus
Verbs: add, subtract

Rules:
- Generate counting scenarios from 11–20 using active book context.
- Present simple math problems. Use smaller numbers for younger age groups.
- Embed problems in realistic situations — not abstract drills.
  e.g. "There are 12 patients on the floor and 5 were just discharged. How many remain?"

### Hand 3: Tens, Hundreds, and Applications
Learning Goal: Count in tens and hundreds; apply numbers practically.
Vocabulary: Ten, twenty... one hundred, one thousand, ordinal numbers (first–tenth), units (inch, pound), time (hour, o'clock)
Verbs: measure, weigh, buy, sell, tell (time)

Rules:
- Practice counting in multiples of ten and hundreds.
- Generate practical scenarios using the active book's domain:
  Workplace: meeting durations, data counts, budget figures
  Hospital: dosages, patient counts, vital sign values
  Daily life: prices, distances, times
- Time-telling exercises must use the target language.

## Completion Criteria
- Player demonstrates recall of 0–10 with no prompting
- Player completes at least one addition and one subtraction problem correctly
- Player uses at least one number correctly in a practical sentence unprompted

## Return
When all three hands are complete and completion criteria are met, confirm completion,
log to progress.json under includes_completed, and offer to return to the active book.
If player was review-triggered, surface the continuity note from the last hand review on return.
